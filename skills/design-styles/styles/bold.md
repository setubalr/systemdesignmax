# Estilo: Bold (`bold`)

> Strong visual presence with heavyweight typography, high-contrast colors, and commanding layouts.

- **Família:** brutalist-bold
- **Usar em:** marcas que precisam de impacto imediato.
- **Evitar em:** leitura prolongada ou dados densos.

## Fundamentos

- **Estilo visual:** bold
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Archivo Black · display=Archivo Black · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#0077BC` |
| secondary | `#009866` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#111111` |
| text | `#111827` |

Papéis de cor declarados: primary, secondary.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels

## Acessibilidade

WCAG 2.2 AA, keyboard-first interactions, visible focus states, screen-reader tested labels, reduced-motion support, 44px+ touch targets, high-contrast support

## Tom de escrita

friendly, professional
