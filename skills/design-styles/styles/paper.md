# Estilo: Paper Design (`paper`)

> Paper-textured, print-inspired design with minimal colors, clean serif/sans typography, and tactile surface qualities.

- **Família:** editorial-warm
- **Usar em:** notas, journals e leitura tátil.
- **Evitar em:** dashboards.

## Marca

Paper design style

## Fundamentos

- **Estilo visual:** minimal, clean
- **Escala tipográfica:** 14/16/18/24/32/40
- **Fontes:** primary=Roboto · display=Montserrat · mono=PT Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#111111` |
| secondary | `#8B5CF6` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
