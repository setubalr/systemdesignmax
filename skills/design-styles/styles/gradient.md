# Estilo: Gradient (`gradient`)

> Smooth color transitions and gradient-rich surfaces for modern, playful interfaces with visual depth.

- **Família:** playful-friendly
- **Usar em:** landing pages vibrantes.
- **Evitar em:** editorial monocromático.

## Marca

Gradient design style

## Fundamentos

- **Estilo visual:** modern, playful
- **Escala tipográfica:** 12/14/16/18/24/30/36
- **Fontes:** primary=Montserrat · display=Space Grotesk · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 8pt baseline grid

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#990FFA` |
| secondary | `#E60076` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, secondary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels

## Acessibilidade

WCAG 2.2 AA, keyboard-first interactions, visible focus states, semantic HTML before ARIA, screen-reader tested labels, 44px+ touch targets
