# Estilo: Artistic (`artistic`)

> High-contrast, expressive style with creative typography and bold color choices for visually striking interfaces.

- **Família:** playful-friendly
- **Usar em:** portfólios, campanhas e cultura.
- **Evitar em:** finanças, saúde ou contextos sóbrios.

## Fundamentos

- **Estilo visual:** high-contrast, artistic
- **Escala tipográfica:** 12/14/16/18/24/30/36
- **Fontes:** primary=Limelight · display=Limelight · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#3B82F6` |
| secondary | `#8B5CF6` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit
- design for empty/loading/error states
- ensure responsive behavior by default
- document accessibility rationale

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid decorative motion without purpose
- avoid ambiguous labels
- avoid mixing multiple visual metaphors
- avoid inaccessible hit areas

## Acessibilidade

WCAG 2.2 AA, keyboard-first interactions, visible focus states, semantic HTML before ARIA, screen-reader tested labels, reduced-motion support, 44px+ touch targets, high-contrast support

## Tom de escrita

concise, confident, professional, action-oriented
