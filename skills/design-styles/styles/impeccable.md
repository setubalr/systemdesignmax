# Estilo: Impeccable (`impeccable`)

> A modern, graphic, editorial-poster aesthetic — warm and confident — built on alternating cream and burnt orange sections, an amber brand color.

- **Família:** editorial-warm
- **Usar em:** portfólios e marcas de estúdio.
- **Evitar em:** dashboards ou dados densos.

## Fundamentos

- **Estilo visual:** modern, clean, high-contrast
- **Escala tipográfica:** 12/14/16/20/24/32
- **Fontes:** primary=Chakra Petch · display=Chakra Petch · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#CC8800` |
| secondary | `#C55221` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
