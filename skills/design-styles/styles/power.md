# Estilo: Power (`power`)

> High-end dark aesthetic with bold headings, monochromatic palette, and premium feel for premium brand experiences.

- **Família:** premium-dark
- **Usar em:** experiências de marca premium.
- **Evitar em:** apps leves e amigáveis.

## Fundamentos

- **Estilo visual:** modern, bold, big headings
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Oswald · display=Oswald · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 8pt baseline grid

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#FAFAFA` |
| secondary | `#FAFAFA` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#000000` |
| text | `#ffffff` |

Papéis de cor declarados: primary.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels

## Acessibilidade

keyboard-first interactions, visible focus states, semantic HTML before ARIA, 44px+ touch targets, high-contrast support
