# Estilo: Expressive (`expressive`)

> Vibrant, personality-driven design with bold colors, playful graphics, and dynamic layouts that balance creativity with structure.

- **Família:** playful-friendly
- **Usar em:** marcas expressivas.
- **Evitar em:** ferramentas sóbrias.

## Marca

A vibrant and visually engaging design style that uses bold colors, playful graphics, and dynamic layouts to create a strong personality. It emphasizes creativity and energy while maintaining clear structure and modern UI patterns.

## Fundamentos

- **Estilo visual:** modern, playful
- **Escala tipográfica:** 14/16/18/24/32/40
- **Fontes:** primary=IBM Plex Mono · display=IBM Plex Mono · mono=IBM Plex Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
