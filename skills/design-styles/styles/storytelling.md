# Estilo: Storytelling (`storytelling`)

> Narrative-driven design using visuals, copy, and interaction to guide users through engaging, emotionally resonant journeys.

- **Família:** narrative-conversion
- **Usar em:** páginas de história e campanhas.
- **Evitar em:** ferramentas utilitárias.

## Marca

a narrative techniques to create engaging, intuitive, and emotionally resonant digital experiences. It guides users through a cohesive journey using visuals, copy, and interaction, transforming functional interfaces into memorable experiences.

## Fundamentos

- **Estilo visual:** playful
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Inter · display=Abril Fatface · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
