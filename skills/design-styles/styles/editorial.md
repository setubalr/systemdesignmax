# Estilo: Editorial (`editorial`)

> Magazine-inspired editorial layout with refined serif typography, structured grids, and elegant reading experiences.

- **Família:** editorial-warm
- **Usar em:** revistas, blogs e portfólios.
- **Evitar em:** dashboards.

## Fundamentos

- **Estilo visual:** modern, editorial
- **Escala tipográfica:** 14/16/18/24/32/40
- **Fontes:** primary=Gelasio · display=Gelasio · mono=Ubuntu Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 8pt baseline grid

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#111111` |
| secondary | `#f1f1f1` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, secondary, neutral, success.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit
- design for empty/loading/error states
- ensure responsive behavior by default
- document accessibility rationale

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels

## Acessibilidade

WCAG 2.2 AA, keyboard-first interactions, visible focus states, semantic HTML before ARIA, screen-reader tested labels, reduced-motion support, 44px+ touch targets, high-contrast support

## Tom de escrita

concise, confident, helpful, clear, friendly, professional, action-oriented, low-jargon
