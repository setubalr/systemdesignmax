# Estilo: Bento (`bento`)

> Modular grid layout with card-like blocks, clear hierarchy, soft spacing, and subtle visual contrast for organized, scannable interfaces.

- **Família:** premium-dark
- **Usar em:** páginas de produto, features e dashboards leves.
- **Evitar em:** narrativas longas contínuas.

## Marca

The bento box style is an innovative design approach that uses a grid layout to present content in visually appealing blocks of varying sizes.

## Fundamentos

- **Estilo visual:** modern, clean
- **Escala tipográfica:** 12/14/16/20/24/32
- **Fontes:** primary=Inter · display=Inter · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |

| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFF5E6` |
| text | `#111827` |

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
