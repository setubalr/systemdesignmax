# Estilo: Neon (`neon`)

> Electric neon glow effects with high-contrast color pairings for bold, attention-grabbing interfaces.

- **Família:** tech-futurist
- **Usar em:** gaming, música e nightlife.
- **Evitar em:** leitura longa.

## Marca

Neon high contrast design

## Fundamentos

- **Estilo visual:** high-contrast
- **Escala tipográfica:** 14/16/18/24/32/40
- **Fontes:** primary=Roboto · display=STIX Two Text · mono=Source Code Pro
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#BBF351` |
| secondary | `#00BCFF` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, secondary.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
