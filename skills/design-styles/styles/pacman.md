# Estilo: Pacman (`pacman`)

> Retro arcade-inspired design with pixel fonts, dotted borders, playful high-contrast colors, and 8-bit game aesthetics.

- **Família:** retro-game
- **Usar em:** games e diversão nostálgica.
- **Evitar em:** produtos sérios.

## Marca

Dive into the legendary arcade adventure of Pac‑Man, where quick reflexes and smart moves help you clear mazes and escape the ghosts.

## Fundamentos

- **Estilo visual:** high-contrast, playful, dotted borders
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Press Start 2P · display=Press Start 2P · mono=Space Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 8pt baseline grid

Papéis de cor declarados: primary, secondary, success, warning, danger, info, surface/subtle layers.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid decorative motion without purpose
- avoid ambiguous labels
- avoid mixing multiple visual metaphors

## Acessibilidade

WCAG 2.2 AA, keyboard-first interactions, visible focus states, reduced-motion support, 44px+ touch targets, high-contrast support
