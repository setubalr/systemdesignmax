# Estilo: Cafe (`cafe`)

> Cozy cafe-inspired interface with warm tones, soft typography, and clean layouts for a relaxed browsing experience.

- **Família:** editorial-warm
- **Usar em:** cafeterias, confeitarias e marcas acolhedoras.
- **Evitar em:** fintechs ou tech sério.

## Marca

A cozy café-inspired interface that blends warm tones, soft typography, and clean layouts to create a relaxed browsing experience

## Fundamentos

- **Estilo visual:** minimal, clean
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Poppins · display=Poppins · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 2/4/8/12/16/24/32/48

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
