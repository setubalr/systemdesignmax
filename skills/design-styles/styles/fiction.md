# Estilo: Fiction (`fiction`)

> A playful, energetic, cartoonesque interface inspired by friendly children's-book illustrations — warm cream backgrounds, big bold custom display typography, saturated brand color blocks, thick black outlines, generously rounded shapes

- **Família:** playful-friendly
- **Usar em:** produtos infantis e lúdicos.
- **Evitar em:** fintechs ou corporativo.

## Marca

A playful, energetic, cartoonesque interface inspired by friendly children's-book illustrations — warm cream backgrounds, big bold custom display typography, saturated brand color blocks, thick black outlines, generously rounded shapes, flat surfaces with almost no shadows, and decorative hand-drawn-feeling illustrations in every section.

## Fundamentos

- **Estilo visual:** playful
- **Escala tipográfica:** 12/14/16/20/24/32
- **Fontes:** primary=Cossette Texte · display=Cossette Texte · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32
