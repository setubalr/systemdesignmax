# Estilo: Shadcn (`shadcn`)

> Shadcn/ui-inspired design with minimal, clean components, monochrome palette, and utility-first patterns.

- **Família:** minimal-clean
- **Usar em:** SaaS modernos com Tailwind.
- **Evitar em:** identidades ilustradas.

## Marca

shadcn style design

## Fundamentos

- **Estilo visual:** minimal, clean
- **Escala tipográfica:** 12/14/16/20/24/32
- **Fontes:** primary=Geist · display=Geist · mono=Fira Code
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#000000` |
| secondary | `#111111` |
| success | `#16A34A` |
| warning | `#D97706` |

Papéis de cor declarados: primary, secondary.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
