# Estilo: Refined (`refined`)

> Carefully curated, modern minimal style with elegant serif typography and understated, sophisticated palettes.

- **Família:** editorial-warm
- **Usar em:** luxo discreto e moda.
- **Evitar em:** vibes caóticas.

## Marca

Refined design style

## Fundamentos

- **Estilo visual:** modern, minimal
- **Escala tipográfica:** 12/14/16/20/24/32
- **Fontes:** primary=Playfair Display · display=Playfair Display · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
