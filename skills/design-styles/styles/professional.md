# Estilo: Professional (`professional`)

> Polished, business-ready design with modern typography, structured layouts, and a trustworthy visual identity.

- **Família:** corporate-data
- **Usar em:** consultorias e serviços.
- **Evitar em:** projetos lúdicos.

## Marca

Electronics shop

## Fundamentos

- **Estilo visual:** modern
- **Escala tipográfica:** mobile-first compact scale
- **Fontes:** primary=Poppins · display=Poppins · mono=IBM Plex Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#FECE14` |
| secondary | `#000000` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, secondary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
