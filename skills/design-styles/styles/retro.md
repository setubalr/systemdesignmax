# Estilo: Retro (`retro`)

> Throwback design with vintage-inspired typography, high-contrast retro palettes, and nostalgic visual elements.

- **Família:** retro-game
- **Usar em:** marcas nostálgicas.
- **Evitar em:** tech de ponta.

## Fundamentos

- **Estilo visual:** high-contrast, retro
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Macondo · display=Macondo · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#3B82F6` |
| secondary | `#8B5CF6` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |

| text | `#111827` |

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
