# Estilo: Premium (`premium`)

> Apple-inspired premium aesthetic with precise spacing, modern typography, and a refined, polished visual language.

- **Família:** premium-dark
- **Usar em:** produtos de alto padrão.
- **Evitar em:** marcas rústicas.

## Marca

Apple design style

## Fundamentos

- **Estilo visual:** modern
- **Escala tipográfica:** 12/14/16/18/24/30/36
- **Fontes:** primary=Inter · display=Inter · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#3B82F6` |
| secondary | `#8B5CF6` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#111827` |

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
