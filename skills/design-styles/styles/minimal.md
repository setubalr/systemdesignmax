# Estilo: Minimal Design (`minimal`)

> Stripped-back design emphasizing whitespace, clean typography, and restrained color for maximum clarity and focus.

- **Família:** minimal-clean
- **Usar em:** portfólios e produtos minimalistas.
- **Evitar em:** quem quer vitrine rica.

## Fundamentos

- **Estilo visual:** minimal, clean, bold
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Open Sans · display=Inter · mono=Inconsolata
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#0C0C09` |
| secondary | `#312C85` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#F4F4F1` |
| text | `#0C0C09` |

Papéis de cor declarados: primary, neutral, success, warning, danger.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels
