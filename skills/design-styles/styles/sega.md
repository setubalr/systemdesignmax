# Estilo: Sega (`sega`)

> A playful, arcade-inspired interface for games — built on the VT323 pixel typeface, hard-edged 0px corners, chunky pill buttons that physically press into solid offset blocks

- **Família:** retro-game
- **Usar em:** jogos retrô.
- **Evitar em:** apps de trabalho.

## Marca

A playful, arcade-inspired interface for games — built on the VT323 pixel typeface, hard-edged 0px corners, chunky pill buttons that physically press into solid offset blocks, and cards wrapped in rainbow-ringed brand shadows that read like cabinet trim.

## Fundamentos

- **Estilo visual:** modern, playful
- **Escala tipográfica:** 13/15/17/21/27/35
- **Fontes:** primary=VT323 · display=VT323 · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32
