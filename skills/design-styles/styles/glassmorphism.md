# Estilo: Glassmorphism (`glassmorphism`)

> Frosted glass effect with translucent layers, subtle blur, and luminous borders for depth and modern elegance.

- **Família:** premium-dark
- **Usar em:** interfaces modernas com profundidade.
- **Evitar em:** densidade extrema de dados (legibilidade).

## Marca

provide fast, reliable communication for individuals, teams, and communities while maintaining a clean interface and high performance across desktop environments.

## Fundamentos

- **Estilo visual:** clean, high-contrast, bold, enterprise, liquidglass effect, glassmorphism
- **Escala tipográfica:** mobile-first compact scale
- **Fontes:** primary=Plus Jakarta Sans · display=Plus Jakarta Sans · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** comfortable density mode
- bento cards

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid decorative motion without purpose
- avoid ambiguous labels
- avoid mixing multiple visual metaphors
