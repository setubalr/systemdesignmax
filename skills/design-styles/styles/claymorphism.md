# Estilo: Claymorphism (`claymorphism`)

> Soft, rounded 3D-like shapes mimicking malleable clay with playful, puffy elements and colorful surfaces.

- **Família:** playful-friendly
- **Usar em:** apps consumer lúdicos.
- **Evitar em:** contextos corporativos.

## Marca

a modern UI trend characterized by soft, rounded, 3D-like, "puffy" shapes that mimic malleable, colorful clay.

## Fundamentos

- **Estilo visual:** modern, high-contrast, playful
- **Escala tipográfica:** desktop-first expressive scale
- **Fontes:** primary=Montserrat · display=Poppins · mono=JetBrains Mono
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 4/8/12/16/24/32

**Evitar**
