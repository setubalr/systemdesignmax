# Estilo: Vibrant (`vibrant`)

> Lively, colorful design with bold playful typography, warm accents, and dynamic visual energy.

- **Família:** playful-friendly
- **Usar em:** marcas jovens.
- **Evitar em:** sobriedade.

## Marca

Vibrant style

## Fundamentos

- **Estilo visual:** modern, clean, bold, playful
- **Escala tipográfica:** 14/16/18/24/32/40
- **Fontes:** primary=Noto Sans · display=Fascinate · mono=Fira Code
- **Pesos:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Espaçamento:** 2/4/8/12/16/24/32/48

## Tokens de cor

| Token | Valor |
|---|---|
| primary | `#7C61D4` |
| secondary | `#EAAE87` |
| success | `#16A34A` |
| warning | `#D97706` |
| danger | `#DC2626` |
| surface | `#FFFFFF` |
| text | `#2F281D` |

Papéis de cor declarados: primary, secondary, neutral, success.

## Regras

**Fazer**
- prefer semantic tokens over raw values
- preserve visual hierarchy
- keep interaction states explicit

**Evitar**
- avoid low contrast text
- avoid inconsistent spacing rhythm
- avoid ambiguous labels

## Acessibilidade

WCAG 2.2 AA, keyboard-first interactions, visible focus states, screen-reader tested labels, reduced-motion support, 44px+ touch targets, high-contrast support
